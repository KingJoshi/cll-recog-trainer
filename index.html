Stored privately in your Google Drive App Data folder (speedcube-trainer-sync.json). Signing in on another machine automatically downloads and merges differences without overwriting your local solves or newer settings. Signing out keeps all local data on this device.

Export or import & merge a local backup file — works offline and across different browser profiles.

⚙️ Google OAuth Client ID Setup

  1. Open Google Cloud Console and enable the Google Drive API.
  2. Create an OAuth 2.0 Client ID (Application type: Web application) and add to Authorized JavaScript origins.
  3. Paste the Client ID above (or set VITE_GOOGLE_CLIENT_ID in .env). If your OAuth consent screen is in Testing mode, add your Google account under Test users.
